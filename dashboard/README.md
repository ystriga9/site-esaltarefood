# Procédures de diagnostic

1. Vérifier les erreurs remontées dans Sentry et analyser les traces.
2. Contrôler la console du navigateur pour les messages `Erreur lors de la requête API` ou `Timeout de la requête`.
3. Réessayer l'appel API avec le serveur de secours si disponible.
4. En cas d'échec persistant, consulter la configuration réseau et les dépendances.
